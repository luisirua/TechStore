TechStore - Tienda de Tecnología

¡Bienvenido al repositorio de TechStore! 

Este proyecto es una página web simulada de venta de artículos tecnológicos. Ha sido desarrollada como parte de una actividad académica para demostrar el uso correcto del control de versiones utilizando Git y GitHub.

Tecnologías Utilizadas

HTML5: Para la estructura semántica de la página.
CSS / Tailwind CSS: Para el diseño, la adaptabilidad (responsividad) y los estilos visuales.
JavaScript: Para la lógica de interactividad, específicamente el carrusel de imágenes.

Estructura del Proyecto

El proyecto cumple con la rúbrica de contener al menos 3 archivos diferentes:
index.html: Archivo principal de código con la estructura de la web.
style.css / script.js: Archivos secundarios de código para estilos e interactividad.
README.md: Este archivo de documentación.

Registro de Actividad (Git)

Durante este proyecto se aplicaron los siguientes conceptos de control de versiones:
Creación de repositorios locales y remotos.
Registro de cambios (commits) con mensajes significativos.
Creación y uso de ramas alternativas (branches) como la rama de pruebas.
Fusión de ramas (merge).
Reversión de cambios (revert).
